title: Local lab

`pnpm local:bootstrap` starts Anvil on chain id 31337 if needed and deploys the protocol. The manifest is `deployments/protocol-local.json`.

Two borrowers are opened in Nectar Sandbox Morpho so the funded-quote scenario and the PropAMM scenario can both run. Debt token symbol is nUSD. It is not USDG.

See [quickstart](../start/quickstart).
